# 需求（评审基线）

> 本文回答「用户要什么、系统必须做到什么、什么算不符合预期」。不写实现、接口与代码位置；评审通过后作为需求基线，实现契约另行维护。

## 1. 用户与目标

| 角色 | 是谁 | 用什么 |
|:--|:--|:--|
| 情侣双方 | 两位使用者，共享同一份记录 | 手机 APP |
| 管理者 | 部署并维护这套服务的人，通常就是其中一位 | 后台网页 |

目标（按优先级）：

1. 随手记下共同生活：文字、照片、视频、录音、心情、地点。
2. 随时回看：时间线、相册、那年今日、地图足迹。
3. 用自然语言问自己的记录，并让 AI 代办整理类操作——必须经用户确认后才执行。

明确不做：

| 不做 | 原因 |
|:--|:--|
| 公开社交（关注、分享链接、陌生人可见） | 只服务一对情侣，内容不外出 |
| 多空间 / 多租户 | 一套部署只对应一对情侣 |
| 自助注册、找回密码 | 账号由管理者创建与重置 |
| Web 前台 | 网页端只给管理者用 |
| 客户端直连第三方 | 模型、地图、更新都由自建服务端中转 |
| 内容编辑（改文字、换图、改日期） | 业务数据只支持新建与删除；要改就删了重发 |

## 2. 信息架构（用户视角）

底部五个域：我们 / 时光 / 相册 / 纪念日 / 足迹，默认落在「我们」。

独立页：设置、通知、AI 助手（这三页不显示底部导航）。
二级页：关于、纪念日列表、添加纪念日、新建相册、相册详情、添加地点、记动态。

| 域 | 用户要完成的事 |
|:--|:--|
| 我们 | 看在一起天数、下一个纪念日、回忆精选、那年今日 |
| 时光 | 看双方发布的动态，点赞、评论 |
| 相册 | 按相册或按月看媒体，管理相册 |
| 纪念日 | 建纪念日、看倒计时、收提醒 |
| 足迹 | 在地图或列表里看一起去过的地方 |

## 3. 场景需求

### 3.1 记录一条动态

| 需求 | 口径 |
|:--|:--|
| 至少一项内容 | 文字 / 心情 / 地点 / 媒体 任选，全空不能发布 |
| 媒体 | 单条最多 9 个；图片、视频、录音可混选；单文件上限：APP 与服务端默认均 500MB（服务端部署可调）；支持 jpg/jpeg/png/webp、mp4/mov/webm、mp3/m4a/wav；HEIC 不支持；0 字节文件拒收 |
| 心情 | 4 个预设（开心 / 平静 / 心动 / 感动）+ 自定义，可清除 |
| 地点 | 输入可搜候选，也可在地图上拖动选点；不填则不带地点 |
| 上传时机 | 点「发布」才上传；失败的那格标红，可重传后再发 |
| 编辑 | 不支持：发布后不能改文字、不能换媒体，只能删除后重发 |
| 权限 | 只有作者能删自己的动态、评论、媒体；对方的内容没有删除入口 |
| 结果 | 发布后双方在「时光」都可见；带地点时该地点进入足迹 |

### 3.2 回看时光

| 需求 | 口径 |
|:--|:--|
| 列表 | 按时间倒序，滚到接近底部自动加载更多 |
| 每条 | 头像、昵称、正文、媒体、时间与地点；点赞按昵称拼接显示，可取消 |
| 评论 | 从底部升起输入框，最长 500 字，可删除自己的评论 |
| 长按 | 正文可复制，本人另有「移入回收站」；评论与媒体的长按同理 |
| 空态 | 「动态圈还空着 / 发一条动态，记录此刻的心情和日常。」+ 发动态入口 |

### 3.3 相册与媒体

| 需求 | 口径 |
|:--|:--|
| 两个视图 | 相册：封面卡 + 数量；时间轴：按月分组的方格，顶部显示总数 |
| 归属 | 一个媒体只属于一个相册；已在别的相册的媒体在选图器里灰显并标出相册名 |
| 新建 | 名称必填、描述可选；建完直接进相册详情 |
| 相册内操作 | 长按媒体：保存到本机 / 移出相册（文件保留，回时间轴）/ 删除（仅作者） |
| 编辑 | 不支持改相册名或描述；往相册里加/移照片是关系增删，不属于编辑 |
| 删除相册 | 相册进回收站，里面的媒体回时间轴，不删文件 |
| 查看器 | 全屏、左右滑切换；照片双击放大；视频点按播放；录音独立播放页 |
| 保存到本机 | 走系统「创建文档」，文件名 `lovelife_<时间戳>` |

### 3.4 纪念日

| 需求 | 口径 |
|:--|:--|
| 新建 | 名称必填；阳历或农历（农历含闰月，并显示对应公历日期）；日期；提前提醒 0–90 天（0 = 不提醒） |
| 列表 | 显示下次公历日期与剩余天数，临近的用颜色强调 |
| 提醒 | 每小时检查一次；到「提前 N 天」当天给双方各发一条站内通知，同一天只发一次 |
| 编辑 | 不支持；提醒天数在新建时设定，之后不能改 |
| 删除 | 进回收站，提醒一并停止 |
| 首页联动 | 「我们」页头卡显示下一个纪念日与剩余天数，点击进入纪念日页 |

### 3.5 足迹

| 需求 | 口径 |
|:--|:--|
| 两个视图 | 地图 / 列表；地图默认中国全境，不自动飞向第一个点位 |
| 未配置瓦片源 | 地图直接写明原因，不白屏 |
| 点位来源 | 发动态带地点、手动添加、AI 代办；同名点位复用 |
| 添加 | 名称必填；可搜索候选、拖地图选点或手填经纬度；到访日期与描述可选 |
| 通知 | 手动或 AI 新增会通知对方；发动态带地点、同名复用不通知 |
| 删除 | 长按移入回收站，提示明确写「动态本身不受影响」 |

### 3.6 我们（首页）

| 需求 | 口径 |
|:--|:--|
| 头卡 | 双头像、双方昵称、开始日期、大字在一起天数、下一个纪念日胶囊 |
| 回忆精选 | 随机封面大图 + 两条文字回忆；「换一批」重抽，「更多」跳时光 |
| 那年今日 | 同月同日的往年记录，点击定位到那条动态 |
| 空态 | 「回忆从今天开始 / 写下第一条，往后每个今天都值得回看。」+ 写第一条 |

### 3.7 通知

| 需求 | 口径 |
|:--|:--|
| 事件 | 对方发动态、赞了你的动态、评论了你的动态；相册与足迹新建；内容被删；纪念日临近 |
| 发送范围 | 交互类通知只发给对方，自己操作不通知自己；删除通知只发给内容创建者，自己删自己的静默；纪念日提醒发给双方各一条 |
| 消费方式 | 点一条 = 消费它（删除）并跳到对应内容；「清空」删掉全部 |
| 红点 | 未消费条数；进入页面时刷新，无系统推送 |

### 3.8 AI 助手

| 需求 | 口径 |
|:--|:--|
| 入口 | 设置里切到「AI 模式」；空会话给一句基于事实的问候 |
| 输入 | 文字、附件（单条 ≤9 个）、五条快捷提问（只填入不发送）、生成中可停止 |
| 回复 | 思考块（可展开）、工具步骤、正文、结果卡；可复制、重新生成；中断的另有编辑重发 |
| 写操作 | 一律先出确认卡，点「确认」才执行；15 分钟未处理自动过期，点「取消」不执行 |
| 结果卡 | 列表 / 宫格 / 统计 / KPI / 详情 / 时间轴 / 地图 7 种；列表可勾选引用（最多 3 条 +N）随下一条消息提交；可「再看几条」翻页 |
| 会话 | 搜索、新建、切换、置顶、删除（直接删除，不进回收站）、批量管理 |
| 边界 | 删除类操作只在 APP 内可用，外部访问令牌一律看不到；AI 不可用时输入禁用并说明原因 |
| 来源标注 | 输入区固定一行「回答由 AI 生成，仅供参考」 |

### 3.9 设置与外观

| 需求 | 口径 |
|:--|:--|
| 分组 | 模式 / 外观 / AI 偏好 / 通用 / 退出登录 |
| 外观 | 深浅三档（跟随系统 / 浅色 / 深色）+ 5 个强调色；只存本机，不跨设备同步 |
| 检查更新 | 行内实时显示：检查中 / 下载中百分比 / 待安装 / 可更新 / 失败 / 已是最新 |
| 关于 | 版本号、服务端地址、连接方式、项目主页 |
| 不在本页 | 资料与空间配置由后台维护；回收站、模型配置、审计不在 APP |

### 3.10 应用内更新

| 需求 | 口径 |
|:--|:--|
| 检查时机 | 启动与登录后各查一次；同一时刻只跑一个检查 |
| 弹窗五态 | 发现新版本（更新说明 + 大小）/ 正在下载（百分比）/ 已就绪 / 失败 / 打开安装器 |
| 稍后 | 记住该版本，同版本不再自动打扰 |
| 强更 | 低于最低支持版本时没有「稍后」，蒙层不可关（下载中除外） |
| 下载 | 关闭弹窗转为后台下载；中断自动续传 |

### 3.11 后台管理（管理者）

管理者只进后台；管理员账号在后台只读（昵称、密码、头像由部署环境管理）。

| 分组 | 能力 |
|:--|:--|
| 仪表盘 | 四项统计（动态 / 照片 / 足迹城市 / 纪念日）+ AI 用量近 14 天、最近活动、异常告警 |
| 空间管理 | 改空间名称、签名、在一起日期；建一对成员（用户名 2–32 字符、密码 ≥6 位）、改昵称、重置密码、头像、生日 |
| AI 配置 | 供应商与密钥、对话与嵌入两条模型链、提示词与输出风格、工具启停、访问令牌 |
| 外部集成 | 通知渠道（Webhook）、地图瓦片源、远程访问、HTTP 代理、应用更新 |
| 回收站 | 可回收内容六类（动态 / 评论 / 照片 / 相册 / 纪念日 / 地图点位）；后台筛选项五类（照片在列表里但不单独筛选）；单条或批量恢复；保留期 7–365 天 |
| 日志 | 审计日志（用户 / 令牌 / AI 三类来源）、操作日志（回收站流水）、服务日志（可跟随与暂停） |

## 4. 全局规则

### 4.1 账号与权限

| 规则 | 口径 |
|:--|:--|
| 角色绑定入口 | 管理员只能进后台，情侣只能进 APP；走错入口直接拒绝并说明 |
| 账号创建 | 只能由管理者在后台建一对；用户名 2–32 字符、密码 ≥6 位；一对只能建一次 |
| 登录失败 | 同一用户名 + 来源连续 5 次密码错误，锁 15 分钟 |
| 登录保持 | 最长 30 天；后台重置密码后，该用户所有设备最迟 1 小时内需要重新登录 |
| 空间日期 | 「在一起日期」不能是未来 |

### 4.2 删除与恢复

| 规则 | 口径 |
|:--|:--|
| 软删 | 内容类删除（动态 / 评论 / 媒体 / 相册 / 纪念日 / 地图点位）都是软删，进回收站，界面提示「仅后台可恢复」；AI 会话删除是直接删除，不进回收站 |
| 永久删除 | 由服务端每天 0 点按保留期执行（7–365 天，默认 30） |
| 可删范围 | 自己的动态、评论、媒体；共同资产（相册、纪念日、地图点位）双方都能删 |
| 级联 | 删相册不删媒体；删最后一条媒体且动态无文字时，整条动态一并进回收站（删前明确告知） |
| 只增删 | 业务数据（动态 / 评论 / 媒体 / 相册 / 纪念日 / 足迹 / 通知）只支持新建与删除，不提供任何编辑入口 |
| 关系操作 | 点赞、加/移相册照片属于关系增删，不算编辑 |
| 配置例外 | 空间资料、成员账号资料、AI 配置、地图源、Webhook、代理、更新属于配置，可在后台修改 |
| 恢复 | 回收站显示摘要、删除时间、删除者；可单条或批量恢复 |
| 审计 | 恢复与永久删除都留流水，永久保留 |

### 4.3 隐私与数据

| 规则 | 口径 |
|:--|:--|
| 数据位置 | 全部在自建服务器；客户端只连这一个服务 |
| 出站范围 | 只允许：模型 API、地图瓦片、通知 Webhook、检查更新用的 GitHub 中转 |
| 密钥 | 密钥类配置只在后台填写，不回显明文；访问令牌明文只在创建时显示一次 |
| 可追溯 | 审计能定位「谁在什么时候做了什么」，来源分用户 / 令牌 / AI 三类 |
| 分享 | 没有对外分享功能；内容只有登录后的双方能看到 |

### 4.4 失败与降级

| 场景 | 用户看到什么 |
|:--|:--|
| 网络失败 | 启动页可重试；已加载内容不丢 |
| AI 未配置 | 入口置灰并给出原因；对话页输入禁用并显示同一句提示 |
| 上传失败 | 单格失败可重传；不会半条发布 |
| 地图未配置瓦片源 | 地图给出明确提示，不白屏 |
| 更新下载失败 | 可重试；已下载部分自动续传 |
| 登录过期 | 提示「登录已过期，请重新登录」 |

### 4.5 上限与时效

| 项 | 值 |
|:--|:--|
| 单条动态媒体 | 9 |
| 单条 AI 消息附件 | 9 个，体积合计 ≤8MB（发消息时按上报元数据拦一次，确认执行时按实际文件体积复核） |
| 单文件上传 | APP 500MB / 服务端默认 500MB（部署可调，APP 按默认值校验） |
| 评论长度 | 500 字 |
| 纪念日提前提醒 | 0–90 天 |
| 回收站保留 | 7–365 天，默认 30 |
| 登录保持 | 30 天 |
| 登录失败锁定 | 5 次 / 15 分钟 |
| AI 写操作确认 | 15 分钟有效 |

## 5. 验收口径（人工可观察）

| 场景 | 通过标准 |
|:--|:--|
| 首次部署 | 后台账号能登录并建出一对成员；APP 用成员账号能登录 |
| 记录 | 发一条带 2 张图、心情与地点的动态，对方可见；足迹出现该地点 |
| 回看 | 时光滚动加载更多；点赞列表显示双方昵称 |
| 删除与恢复 | 删一条动态后 APP 消失、后台回收站可见、恢复后回到原处 |
| AI 查询 | 问「这个月记了几条」，返回结果卡而不是纯文本 |
| AI 写入 | 说「帮我记一条…」，先出确认卡，确认后动态出现 |
| 更新 | 后台放入并下载完新版本后，APP 检查更新提示可安装 |
| 无编辑入口 | 动态、评论、媒体、相册、纪念日、足迹的详情与列表里都找不到「编辑」；改内容只能删了重发 |

## 6. 待评审的决策

| 问题 | 现状 | 需要决定 |
|:--|:--|:--|
| 通知 | 只有站内红点，进入页面才刷新 | 是否要系统推送 |
